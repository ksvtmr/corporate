# Отчет о выполнении: Реструктуризация в автономный Corporate Frontend

* **Дата**: 2026-09-02
* **Области**: frontend
* **Статус**: Выполнено

## Описание задачи
Реструктуризация монорепозитория Corporate в выделенный, полностью автономный frontend-репозиторий без зависимостей от локально запущенного бэкенда или Docker-инфраструктуры.
1. Удаление монорепозиторных слоев (`backend/`, `infra/`, `docker-compose.yml`).
2. Размещение frontend-приложения непосредственно в корне репозитория (`package.json`, `vite.config.ts`, `tsconfig.json`, `src/`).
3. Интеграция дизайн-системы `@iclever/frontend-kit` в `src/kit/` с поддержкой алиасов.
4. Разработка полноценного локального Mock API Engine (`src/mocks/`) с сохранением состояния в `localStorage` для всех сценариев (аутентификация, профиль, оргструктура, сотрудники, инвайты, пагинация, CSV импорт/экспорт).
5. Составление исчерпывающей документации API контрактов для бэкенд-команды в файле `API_CONTRACTS.md`.
